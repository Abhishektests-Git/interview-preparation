# Interview Preparation

Abhishek's SDET interview preparation — interactive explainers and study guides, all in one place.

## Contents

- **`index.html`** — CI/CD Pipeline Animation: an animated walkthrough of a
  CI/CD pipeline — how test cases run in the QA environment before a build
  reaches production, and what happens when a test fails (the defect loop
  back to the developer, a new build, and a re-run). Includes a "How
  Jenkins works" section (server, job/pipeline, stages, agents, triggers,
  reports).
- **`sorting-algorithms-visualizer.html`** — Sorting Algorithms Visualizer:
  step-by-step animations of Bubble, Selection, Insertion, Merge, Quick and
  Heap sort with play/pause, step controls, speed and array-size sliders,
  live comparison/swap counters and plain-English narration for every step.
- **`SDET_Complete_Roadmap.pdf`** — The Complete SDET Roadmap: the full
  skill map with an honest status per area, 7 phases in order, an
  integrated 12-week study calendar, a round-by-round interview map, and a
  readiness checklist.
- **`Interview_Question_Bank.pdf`** — Interview Question Bank: 89
  interviewer questions with model answers written from Abhishek's own
  experience at TCS (Lloyds and Aviva) — project and defect stories,
  manual testing, SQL, Java, Selenium in depth plus a Selenium
  deep-dive follow-up section, TestNG/Maven/Jenkins/Git, framework
  judgement, scenarios, HR, and a one-page quick revision.
- **`SQL_Window_Functions_Notes.pdf`** — SQL Window Functions Notes:
  study notes from a 20-slide guide to SQL window functions — the big
  idea (detail rows stay visible, unlike GROUP BY), the OVER() anatomy
  (PARTITION BY, ORDER BY, frames), ROW_NUMBER vs RANK vs DENSE_RANK,
  aggregates as windows and running totals, LAG/LEAD, FIRST_VALUE and
  the LAST_VALUE trap, NTILE, ROWS vs RANGE frames, the Top-N-per-group
  and latest-record-per-group patterns, common mistakes, and 10
  interview questions with a practice set.
- **`Java_OOP_Notes.pdf`** — Java OOP Notes: complete study notes from
  Kunal Kushwaha's "Object Oriented Programming (OOP) in Java" YouTube
  playlist (all 7 videos) — classes and constructors, static and
  singleton, inheritance and polymorphism, access control and the Object
  class, abstract classes and interfaces, generics, lambdas, exception
  handling, cloning, collections and enums. 77 concepts, 47 code
  snippets, rules to remember and interview takeaways per section.
- **`Docker_Notes.pdf`** — Docker Notes: the 10 core Docker concepts in
  plain words — Docker vs virtual machines, image vs container,
  Dockerfile, build and run, port mapping, volumes, networks,
  environment variables, Docker Compose, and registry/Docker Hub —
  with commands in VS Code style, 8 interview Q&As including the
  honest "have you used Docker?" answer, and a one-page quick
  revision.
- **`genai-llm-animated-explainer.html`** — Gen AI & LLMs Animated
  Explainer: beginner notes that move — a chat demo that generates an
  answer token by token, a sentence splitting into token chips,
  an embeddings word map where similar words cluster, next-token
  probability bars, attention arcs, training vs inference, a
  temperature slider you can play with, a hallucination that gets
  stamped "sounds right ≠ is right", a 5-station RAG pipeline, and
  tool calling, agents and multimodal — plus a quick-revision grid.
  Awareness learning for interviews, honestly framed.
- **`genai-llm-complete-notes.html`** — Gen AI & LLM Complete Study
  Notes: the full from-scratch course — AI vs ML vs deep learning vs
  GenAI, what an LLM really is (parameters, weights), tokens,
  embeddings, next-token prediction, attention and transformers,
  context window, pretraining, fine-tuning, RLHF and LoRA, inference,
  temperature and sampling, prompt engineering (system prompts,
  few-shot, chain-of-thought), hallucination, RAG with chunking and
  vector databases, RAG vs fine-tuning, tools, agents, multimodal,
  LLM APIs, the model landscape, limits, evaluation, and GenAI for
  testers — 25 animated sections with a 29-term revision grid and
  six model interview answers. Self-contained: learn the whole
  topic from this one page.
- **`sql-fundamentals-animated-notes.html`** — SQL Fundamentals
  Animated Notes: study notes from the "SQL 500 Interview Questions,
  Part 1" carousel (Q1–39) — why not SELECT *, the data-type
  families, the INT family, CHAR vs VARCHAR, DECIMAL vs FLOAT
  (money is always DECIMAL), date/time types and the timezone trap,
  a full NULL section (NULL = UNKNOWN, three-valued logic, why
  WHERE <> silently drops NULL rows), COALESCE and NULLIF, casting,
  collation and Unicode, LIKE patterns, and ORDER BY with NULLs —
  all with animated scenes, examples on a POLICIES table, a
  21-card revision grid and five model interview answers.
- **`java-programming-animated-notes.html`** — Java Programming
  Animated Notes: study notes from the "Java Programming: Complete
  Beginner to Advanced" carousel — introduction and the JVM,
  JDK/JRE/JVM, program structure, variables and data types,
  input/output, operators, conditionals, loops, arrays and 2D
  arrays, Strings (equals vs ==, StringBuilder, palindrome),
  methods (pass-by-value, overloading, varargs, recursion),
  classes and objects, the four OOP principles, inheritance vs
  composition, polymorphism (upcasting and WebDriver dispatch),
  abstraction and interfaces, packages and access modifiers —
  17 animated sections with VS Code-style code, a 26-term
  revision grid and six SDET interview answers.
- **`prompt-engineering-animated-notes.html`** — Prompt Engineering
  Animated Notes: study notes from the "Prompt Engineering: Complete
  Beginner to Advanced" carousel — AI/GenAI/LLM basics, tokens,
  the anatomy of an effective prompt, basic techniques (zero-shot,
  one-shot, few-shot, instruction, iterative), advanced techniques
  (chain-of-thought, decomposition, self-consistency, ReAct,
  reflection, role/persona), context engineering and RAG grounding,
  structured JSON output, weak vs strong prompts, prompting for
  coding, content, education and data, multimodal prompting and
  responsible use — 12 sections with interactive demos (a live
  tokeniser, a prompt builder, an animated chain-of-thought and
  RAG pipeline), a 16-term revision grid and six SDET interview
  answers.
