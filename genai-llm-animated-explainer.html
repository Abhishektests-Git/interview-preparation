What is Generative AI? What is an LLM?

Old AI picked answers from a fixed list. Generative AI creates brand-new text, images and code. An LLM (Large Language Model) is the text kind.

You
LLM
The one-line story: an LLM is autocomplete that read the whole library. Your phone keyboard guesses the next word after seeing a little of your typing — an LLM does the same trick after reading billions of pages.
Watch the answer appear word by word — that’s really how it generates.

Important: an LLM is not a search engine. It doesn’t look facts up — it predicts text that sounds right. Looking facts up is RAG’s job (scene 9).

RememberGenerative AI creates new content; an LLM is a giant next-word predictor trained on text.

Tokens — the model can’t read words

Before anything else, your text is chopped into small pieces called tokens. Each piece gets a number (an ID). The model only ever sees numbers.

“Testing makes software reliable”
Watch one sentence break into numbered pieces.
RememberThe model never sees words — only token numbers. Rough rule: ~4 characters ≈ 1 token, so 100 tokens ≈ 75 words.

Next-token prediction — the whole trick

This is all an LLM really does: read what came so far, guess the next token with probabilities, pick one, then repeat. Sentences are built one token at a time.

Attention — who is “it” talking about?

Read this sentence: who was tired — the animal, or the street? You knew instantly. Attention is how the model knows: every word looks at all the other words and decides who matters.

Sampling & Temperature — how wild should the guess be?

The model has probabilities for the next token. Sampling is how it picks one. Temperature is the dial that controls how adventurous the picking is. Drag it and watch the bars change shape.

greedy — always pick the top bar. Same answer every time; safe but can get repetitive.
top-k — pick randomly, but only from the k best guesses (say the top 40).
top-p — pick from the smallest set of guesses whose probabilities add up to p (say 90%).
No play button needed — this scene is yours. Slide the temperature and watch “mat” lose its crown.
RememberLow temperature = one bar dominates, safe and repetitive. High temperature = bars flatten out, creative but risky.

Tools, Agents & Multimodal — beyond plain chat

Three upgrades that turn a text predictor into something that can do things. Each card has its own tiny play button.

🔧 Tool calling

The LLM can ask an outside tool for help, then use the result.

You ask: 457 × 32 = ?
LLM thinks: “Maths isn’t my strength — call the calculator.”
Calculator returns: 14624
LLM answers using it: 457 × 32 = 14,624

🤖 Agents

An LLM that plans steps and loops until the job is done.plan → act → check → repeat

Goal: “Book the cheapest flight to Delhi.”
Plan: search flights → compare prices → check timings.
Act: runs the search tool.
Check: “Prices found, but one lands at 2 AM — search again.”
Done: best sensible flight picked, summary given.

🖼️ Multimodal

Not just text — the model can also take in images (and audio/video).

You send this picture + ask: “What’s in this picture?”
The model “sees” the image and reads your text together.
Answer: “A cat sitting on an orange mat.”
RememberTools = the LLM borrows abilities. Agents = the LLM plans and loops. Multimodal = more than text goes in.

Quick revision — every term in one line

The night-before-the-interview grid. If you can say each of these out loud, you know this topic.

TokenA small piece of text (part of a word) turned into a number — the only thing the model actually reads.
EmbeddingA list of numbers that captures a token’s meaning; similar meanings sit close together.
Context windowHow much text the model can “see” at once — its short-term memory for this chat.
TransformerThe architecture (design) behind modern LLMs, built around attention.
AttentionHow each word weighs the other words to understand who matters in a sentence.
PretrainingThe first, huge training phase: predicting text from books, websites and code.
Fine-tuningExtra training on specific examples to make the model better at a particular job.
InferenceUsing the trained model to generate an answer — what happens on every chat.
TemperatureThe dial for randomness: low = safe and repetitive, high = creative and risky.
Top-k / Top-pWays to limit the guessing pool: only the k best tokens, or the smallest set adding up to probability p.
HallucinationWhen the model confidently generates something false, because it predicts likely text, not truth.
RAGSearching your documents first and answering from them — open-book instead of memory-only.
ChunkingCutting documents into small pieces so the search step in RAG can find and pass the right ones.
AgentAn LLM that plans steps, uses tools, checks its own progress and loops until the task is done.

🎤 Say it in an interview — “What is an LLM?”

“An LLM is a large language model — an AI trained on a huge amount of text to predict the next token, given everything before it. It reads text as tokens, understands relationships between words through attention, and generates answers one token at a time. It predicts likely text rather than looking facts up, which is why techniques like RAG are used to ground it in real documents.”

One honest note: this page is awareness learning for interviews — understanding the concepts well enough to explain them clearly. It is concept knowledge, not project experience, and should be presented that way.
RememberTokens in → embeddings give meaning → attention connects words → next-token prediction writes the answer. Everything else is an upgrade on that loop.
